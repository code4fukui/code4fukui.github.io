# Code for FUKUI

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)


![Code for FUKUI Logo](code4fukui_logo.png)


**Code for FUKUI** is a civic tech organization that solves regional challenges through technology. This repository hosts the main website and a collection of related civic tech projects for the Fukui region in Japan.

## Featured Projects

Code for FUKUI develops a wide range of applications and open data initiatives. Here are a few examples:

- **[Digital Twin Echizen](digitaltwin/):** An ambitious project to create a digital twin of the city of Echizen in the metaverse.
- **[XR Gourmet](https://code4fukui.github.io/xrgourmet/):** An open data collection of 3D scanned local cuisine, viewable in AR/VR.
- **[Find Fire Hydrants](https://code4fukui.github.io/findhydrant/):** A tool to help citizens locate and clear fire hydrants during heavy snowfall, based on 5-star open data.
- **[VR Tojinbo](https://code4fukui.github.io/vr-tojinbo/):** A virtual reality experience of Tojinbo, a famous scenic spot in Fukui.
- **[Fukui Tourism Data Analysis](https://code4fukui.github.io/fukui-kanko-stat/):** Interactive analysis of open data from tourism surveys in Fukui Prefecture.

> For a comprehensive list of all projects, please visit our official website: [code4fukui.github.io](https://code4fukui.github.io/)
