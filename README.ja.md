# Code for FUKUI

![Code for FUKUI ロゴ](code4fukui_logo.png)

**Code for FUKUI** は、テクノロジーで地域の課題を解決するシビックテック団体です。このリポジトリでは、メインのウェブサイトと、福井地域に関連するシビックテックプロジェクトのコレクションをホストしています。

## 主なプロジェクト

Code for FUKUIは、幅広いアプリケーションやオープンデータの取り組みを展開しています。以下はその一例です：

- **[デジタルツイン越前](digitaltwin/):** メタバース上に越前市のデジタルツインを構築する野心的なプロジェクト。
- **[XRグルメ](https://code4fukui.github.io/xrgourmet/):** AR/VRで閲覧可能な、地元グルメの3Dスキャン・オープンデータコレクション。
- **[消火栓を探す](https://code4fukui.github.io/findhydrant/):** 5つ星オープンデータを活用し、豪雪時に市民が消火栓を見つけて除雪するのを支援するツール。
- **[VR東尋坊](https://code4fukui.github.io/vr-tojinbo/):** 福井県の有名な景勝地「東尋坊」のVR（バーチャルリアリティ）体験。
- **[福井県観光データ分析](https://code4fukui.github.io/fukui-kanko-stat/):** 福井県の観光動態調査のオープンデータをインタラクティブに分析。

> すべてのプロジェクトの包括的なリストについては、公式ウェブサイトをご覧ください：[code4fukui.github.io](https://code4fukui.github.io/)
